# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## identities

候选身份不预置唯一答案。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 标识 |
| `area` | string | 常见区域 |
| `confirmed` | boolean | 独立身份已确认 |

## identity_links

人工候选及后来确认。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 关系 |
| `left` | string | 标识 |
| `right` | string | 标识 |
| `state` | string | 候选或确认 |
| `known_day` | integer | 知悉日 |

显式引用：`left` → `identities.id`；`right` → `identities.id`。

## efforts

固定巡看窗口和实际努力分钟。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 窗口 |
| `area` | string | 区域 |
| `day` | integer | 日序 |
| `minutes` | integer | 巡看分钟 |
| `planned` | boolean | 计划窗口 |
| `state` | string | 完成或未观察 |

## sightings

发现记录关联努力窗口，不自带总数量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 发现 |
| `window` | string | 窗口 |
| `identity` | string | 标识 |
| `count` | integer | 同次重复照片数 |

显式引用：`window` → `efforts.id`；`identity` → `identities.id`。

## services

真实服务事实，手术凭证仅一份。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 服务 |
| `identity` | string | 标识 |
| `kind` | string | 绝育或照护或领养或退养或转移 |
| `day` | integer | 日序 |
| `cost_cents` | integer | 成本 |
| `area` | string | 区域 |
| `proof` | string | 凭证 |

显式引用：`identity` → `identities.id`。

## funds

不同资助用途和稳定期。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 资助 |
| `kind` | string | 首次绝育或持续照护或稳定领养 |
| `stable_days` | integer | 稳定日 |
| `unit_cents` | integer | 支持上限 |
| `paid_adjustment` | string | 允许已付调整 |

## claims

真实申领和已付金额。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 申领 |
| `fund` | string | 资助 |
| `service` | string | 服务 |
| `paid_cents` | integer | 已付 |
| `known_day` | integer | 知悉日 |

显式引用：`fund` → `funds.id`；`service` → `services.id`。

## priorities

敏感区投诉只作为现场事实，不预置效果。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 区域记录 |
| `area` | string | 区域 |
| `sensitive` | boolean | 敏感区域 |
| `complaints` | integer | 独立投诉 |
| `observation_slots` | integer | 下期观察窗口 |
| `review_slots` | integer | 救助复核窗口 |
| `care_reserved` | integer | 既有照护占用 |
